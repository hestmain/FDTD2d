# fdtd2d 原理说明

本文说明 fdtd2d 的方程、离散方法、稳定性限制，以及哪些结果已经验证。接口、数据结构和完整系数表见 [api 文档](api/DEV.md)，这里不重复。

## 1 物理模型

介质是静止的无黏性理想流体，声波是小扰动，方程线性化。未知量是声压 p 和质点速度 v = (vx, vy)。一阶方程组由连续性方程和欧拉方程组成：

```
∂p/∂t = −K ∇·v + K·q          K = ρc²
∂v/∂t = −(1/ρ) ∇p
```

ρ 是密度，c 是声速，K 是体积模量，q 是声源项（第 5 节）。二维指所有量沿 z 方向不变，因此体积、能量和声源强度都按单位深度计：声能单位是 J/m，点源强度 Q 的单位是 m²/s。

## 2 离散

网格是均匀矩形网格，单元尺寸 dx、dy。变量按 Yee 方式错开存放：p 在单元中心，vx 在 x 面，vy 在 y 面。一行 nx 个单元有 nx+1 个 x 面，一列 ny 个单元有 ny+1 个 y 面。多出来的是最外侧的面，那里只有一侧有单元，速度由边界条件决定（第 4 节）。数组布局见 [solver.md](api/solver.md) 的“未知量与位置”。

空间导数用二阶中心差分。每个差分跨过一个单元或一个面，p 的梯度落在面上，v 的散度落在单元中心，不需要插值。

时间用 leapfrog：p 在整数时刻 t_n = n·dt，v 在半整数时刻 t_{n+½}，交替更新。无阻尼、无声源时的更新为：

```
vx^{n+½}(i,j) = vx^{n−½}(i,j) − dt/ρ_face · ( p^n(i,j) − p^n(i−1,j) ) / dx
vy^{n+½}(i,j) = vy^{n−½}(i,j) − dt/ρ_face · ( p^n(i,j) − p^n(i,j−1) ) / dy

p^{n+1}(i,j) = p^n(i,j) − K·dt · [ ( vx(i+1,j) − vx(i,j) ) / dx
                                 + ( vy(i,j+1) − vy(i,j) ) / dy ]
```

后一式中的 v 取 v^{n+½}。ρ_face 是面两侧单元密度的算术平均。代码把 p 拆成 px + py 两个分量以实现 PML，σ = 0 时拆分不改变结果。

## 3 稳定性与精度

显式 leapfrog 在二维交错网格上稳定的条件是：

```
cfl = c·dt·√(1/dx² + 1/dy²) ≤ 1
```

c 取介质表中的最大声速。未指定 `dt` 时，model 按 `cfl`（默认 0.7）反算 `dt = cfl / (c·√(1/dx² + 1/dy²))`。指定了 `dt` 且 cfl > 1 时，`model_build` 报错。solver 自己不检查这个条件。

数值色散随每波长点数减少而增大。model 按 `c_min / (f_max · max(dx, dy))` 估计每波长点数，f_max 是所有声源的最高频率。低于 10（`MODEL_MIN_POINTS_PER_WAVELENGTH`）时输出警告：

```
only %.2f points per wavelength at %g Hz (recommended >= 10); reduce dx/dy or the source frequency
```

警告不中止运行。10 是经验值，不是误差界。

测试中的实测值：空气（ρ = 1.21 kg/m³，c = 343 m/s）、dx = 1 cm、cfl = 0.7、1500 Hz（约 23 点/波长，由这些参数算出）时，沿 x 轴的相位延迟相对误差为 0.3 %，对角线方向为 0.14 %。这些数值只对该分辨率成立，换分辨率后误差会变。其余算例见 [solver.md](api/solver.md) 的“验证”。

## 4 边界

**刚性**（`rigid`）：最外侧面上法向速度 v = 0。

**压力释放**（`pressure_release`）：边界上 p = 0。在最外侧面外放一个镜像虚单元，取反对称 `p_ghost = −p_inside`。虚单元中心与内部单元中心分处面两侧，各距面 dx/2，p = 0 的平面正好落在面上。

**固体单元**：障碍物形状覆盖单元中心的单元记为固体单元，边界按单元呈阶梯状。固体单元内 p = 0，与它相邻的面上 v = 0。这两条规则编进了系数，时间循环里没有针对固体的分支。

**PML**（`pml`）：在物理域外附加 `thickness` 个单元的吸收层，只加在设为 `pml` 的边上。PML 内 p 拆成 px 与 py，两个方向分别阻尼：

```
∂px/∂t + σx·px = −K ∂vx/∂x + 源项的一半
∂py/∂t + σy·py = −K ∂vy/∂y + 源项的一半          p = px + py
∂vx/∂t + σx·vx = −(1/ρ) ∂p/∂x
∂vy/∂t + σy·vy = −(1/ρ) ∂p/∂y
```

阻尼按深度 d（从物理域边缘算起）多项式增长，物理域内 σ = 0：

```
σ(d) = σ_max · (d/L)^m
σ_max = −(m+1) · c · ln(R) / (2L)          L = thickness · dx（y 侧用 dy）
```

R 是垂直入射波往返一次的理论反射系数，m 是剖面指数，c 取最大声速。默认 thickness = 20，R = 1e-6，m = 2。R 是连续介质中的值，离散网格上的实际反射更大。

阻尼项取新旧时刻的平均（半隐式）。设 h = σ·dt/2，则 `f_new = (1−h)/(1+h)·f_old − dt/(1+h)·rhs`，σ = 0 时退化为无阻尼更新。

PML 的最外侧面是刚性壁：波穿过 PML，被最外缘反射，再穿回物理域，沿途两次衰减。固体单元伸进 PML 会反射波，model 对此发出警告。

## 5 声源

声源是软源，以单极子体积注入的形式加到压力方程的源项里，而不是直接设定压力，因此波经过声源位置时不会被反射。每步在 t_{n+½} 对每个声源单元 c 做：

```
p_c += K·dt · w_c · s(t_{n+½})
```

实现中增量平分给 px 和 py。w_c 是空间权重，s(t) 是时间函数。

- 点源：权重按双线性分配到最近的 4 个单元中心，Σ w·dx·dy = 1。幅值 A 是单位深度的体积速度 Q，单位 m²/s。
- 线源（直线段）：权重取线段落在各单元内的长度，Σ w·dx·dy = 线段长度。幅值 A 是单位长度、单位深度的体积速度 Q′，单位 m/s。

归一化使总注入量与网格尺寸无关。时间函数是带升余弦起振渐变的简谐信号：

```
s(t) = A · ramp(t) · sin(2πft + φ)
ramp(t) = ½ · (1 − cos(πt/T_r))   t < T_r,    1   t ≥ T_r
T_r = ramp_cycles / f
```

`ramp_cycles` 默认 3，设为 0 则不渐变。

参考解：二维自由场中简谐点源（`e^{iωt}` 约定）的远场为 `p(r) = (ωρQ/4) · H₀⁽²⁾(kr)`。用它校核幅值的测试尚未实现，是计划项。

## 6 验证现状

下列结果来自 `tests/test_solver.c`（空气，dx = 1 cm，cfl = 0.7），完整数据见 [solver.md](api/solver.md) 的“验证”。

已验证：

- 封闭无损域（刚性、压力释放、含障碍物、dy ≠ dx）中，leapfrog 精确守恒量的偏差约 5×10⁻¹⁵，阈值 1×10⁻¹¹。
- 四边 PML、厚度 20 个单元，驱动 3 个周期后关闭声源，终态能量与峰值能量之比约 6×10⁻⁸（各向同性）和 8.5×10⁻⁸（dy = 2dx），阈值 10⁻³。这是封闭盒内总能量的衰减，不是某个入射角的反射系数。
- 刚性盒内居中声源的场在 x 镜像、y 镜像和转置下一致，偏差不超过 10⁻¹²·max|p|。
- 相速度：轴向相位延迟误差 0.3 %，对角线 0.14 %。

尚未验证：

- 绝对幅值没有与解析解比较。`tests/test_validation.c` 目前是占位程序（返回 77，CTest 视为跳过），计划比较自由场点源与 Hankel 函数解，以及两侧刚性壁之间线源产生的平面波幅值。
- 单一入射角下的 PML 反射系数没有测量。介质界面上的反射与透射没有验证。
